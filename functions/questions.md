# FUNCTIONS

### Defination 
    ---

1. **Basic function syntax.**\
    **problem** : write a function to calculate and return the square of the number.

2. **Function with multiple parameters**\
    **problem** : Create a function that takes two numbers as parametrs and returns their sum.

3. **Polymorphism in functions**\
**problem** : write a function multiply that multiplies two numbers, but can also accept and multiply strings.

4. **Function returning Multiple variables**\
**Problem** : create a function that returns both area and circumference of a given its radius.

5. **Default parameter value**\
**Problem** : Write a function that greets a user. If no name is provided, it should greet with a default name.

6. **Lambda Function**\
**Problem** : create a lambda function to compute the cube of number.

7. __Function with *args__\
**Problem** : create a function that takes variable number of arguments and returns their sum.

8. __Function with **kwargs__\
**Problem** : create a function that accepts any number of keyword arguments and prints them in the format key:value.

9. **Generator function with yield**\
**Problem** : Write a generator function that yields even numbers upto a specified limit.

10. **Recursive Function**\
**Problem** : Create a recursive function to calculate the factiorial of a number.
